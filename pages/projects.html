DataSmith

: Cross-platform SQL Database Populator for Custom Test Data Generation :

I got tired of writing test@example.com in every project and asking ChatGPT for realistic insert queries, so I built DataSmith: a free, cross-platform desktop app that generates realistic SQL data with almost no setup. It auto-detects your DB schema, supports Faker, regex, Python snippets and foreign keys, and can export .sql or insert directly. It started as DataForge, a Python CLI tool, and grew into a GUI app with far more features.

Skills: Tauri React Rust SQL Python LangChain

Healie

: Personal Health Assistant :

Healie (Health + Genie) is a prototype personal health assistant that won Best Use of AI/ML at ScaleHack '24 (Med Hack), a Government of Kerala-backed hackathon. You upload your diagnosis and test results, and it gives a second opinion on your treatment, because misdiagnosis is more common than most people expect.

Skills: Flutter FastAPI AI/ML

TheLifeOfPy

: A Simple Artificial Life Simulator :

Inspired by the works of @PrimerBlobs, @davidrandallmiller, and @3Blue1Brown, I've wanted to build something like this for a long time. My BTech final project felt like the perfect excuse to finally do it. So, here's TheLifeOfPy, my attempt at creating a simple artificial life simulation software where you can create organisms by customizing their phenotypic and genotypic traits (like neural networks, size, color, and defense mechanisms) and release them into an environment to see how they interact.

Skills: Pygame AI Python

ZTLAB

: A wrapper for ETLAB; A campus management app :

ZTLAB is an Android app built as a wrapper around ETLAB, a campus management system used across multiple colleges in Kerala. The app extends ETLAB's limited functionality with a cleaner interface and attendance tracking, built with React Native on the frontend and FastAPI handling the scraping backend.

GridNavigatorRE

: Reinforcement Learning based Grid Navigator :

My first Reinforcement Learning project, GridNavigatorRE is a simple grid navigator that uses the DQN algorithm in a custom environment to train an agent to navigate to a fixed goal while avoiding obstacles on the path. It took months of iteration, and watching the agent go from crashing into the first obstacle to reliably reaching the target made it worth it.

Skills: Pygame Numpy Gymnasium PyTorch Stable Baselines 3
